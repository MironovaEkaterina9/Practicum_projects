# 🎮 Проект: Анализ продуктовых и маркетинговых метрик игры «Секреты Темнолесья»

## 📝 Описание проекта: Проект посвящен исследованию поведения игроков, анализу внутриигровых покупок и решению операционных (ad-hoc) задач для маркетинговой команды.

Продажа внутриигровой валюты **«райские лепестки»** за реальные деньги — это основная статья дохода команды разработки игры «Секреты Темнолесья». В рамках стратегии масштабирования команда планирует запустить рекламную кампанию для привлечения новых платящих пользователей и продвижения покупок эпических предметов. 

Данный проект направлен на исследование текущего монетизационного поведения аудитории, чтобы предоставить команде маркетинга и гейм-дизайна дата-обоснованные инсайты для настройки рекламы.

**Какую проблему решает:** Помогает оценить текущую структуру доходов от монетизации и выявить наиболее перспективные когорты игроков для таргетинга рекламы.

**Бизнес-цели исследования:**
1. **Анализ конверсии в покупку валюты:** Выяснить, какая доля игроков покупает внутриигровую валюту «райские лепестки» за реальные деньги, и оценить базовый Paying Share проекта.
2. **Сегментация по расам:** Изучить зависимость доли платящих игроков от выбранной расы персонажа для последующей оптимизации рекламных креативов.
3. **Исследование внутриигровых покупок и очистка данных:** Рассчитать основные статистические показатели стоимости покупок эпических предметов за «райские лепестки», выявить и исключить транзакции с нулевой стоимостью для предотвращения искажения метрик, а также сформировать очищенный рейтинг популярности эпического контента.
4. **Решение ad hoc задач:** Оперативно ответить на точечные запросы маркетинговой команды игры «Секреты Темнолесья» для оптимизации текущих бизнес-показателей.
